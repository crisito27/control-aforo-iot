# Control de Aforo IoT

Proyecto académico de control de aforo con Raspberry Pi, sensores, microservicios, Firestore y Vercel.

## Datos de prueba

La carpeta `data/` contiene **datos simulados** generados únicamente para desarrollo, pruebas del dashboard y validación de la lógica. **No corresponden a la medición real de 7 días exigida por la evaluación.**

Cuando la Raspberry Pi quede funcionando, los datos reales deben capturarse desde los sensores y enviarse a Firestore para la medición oficial.
